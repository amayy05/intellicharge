# IntelliCharge — Seed Data Documentation

**All data below is SYNTHETIC / SAMPLE. It is not live operational data.**

---

## Charging Stations

**Source:** `data/raw/mmr_palghar_stations.json`  
**Origin:** OpenChargeMap export for MMR/Palghar region  
**Count:** 25 stations  
**Status:** Real geographical locations, clearly labeled in UI as sample data

| Field | Note |
|---|---|
| `id` | Deterministic slug (e.g. `st-palghar-01`) |
| `latitude/longitude` | Real coordinates from OpenChargeMap |
| `connector_types` | Real connector types for Indian EV market (CCS2, Type 2, CHAdeMO) |
| `charger_count` | From OpenChargeMap; may not reflect current availability |
| `power_kw` | From OpenChargeMap |
| `pricing_per_kwh` | **Sample pricing** — labeled as sample in UI |
| `amenities` | Sample from station metadata |

Seed is idempotent — re-running `python seed_db.py` updates stations without duplicating.

## Synthetic Queue History

**File:** `data/synthetic_queue_history.json`  
**Generated by:** `data/generator/queue_generator.py`  
**Duration:** 75 days of synthetic data  
**Records:** ~100,000+ snapshots  
**Seed:** Deterministic per station_id + timestamp  

This data is used to train the ML wait-time prediction model. It is **not real historical queue data**.

---

## ML Model Artifacts

| Artifact | Path | Note |
|---|---|---|
| `wait_time_model.joblib` | `data/models/wait_time_model.joblib` | RandomForest trained on synthetic queue history |
| `feature_pipeline.joblib` | `data/models/feature_pipeline.joblib` | Feature extraction pipeline |

Model metrics are from held-out synthetic data — **not validated against real-world observations**.  
Predictions are labeled as `confidence_source: "model"` (ML inference) or `"heuristic"` (fallback).

## How to Reset

```powershell
# From repository root:
cd backend

# Delete and recreate the database
Remove-Item intellicharge.db -Force
python seed_db.py

# This will:
# 1. Recreate schema
# 2. Load 25 stations
# 3. Generate/load 75-day synthetic queue history
# 4. Train the ML model
# 5. Create demo user
```

**Warning:** Do not run seed against a production database. The script seeds test/demo accounts and may overwrite station data.
